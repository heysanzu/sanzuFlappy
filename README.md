# Flappy

A lightweight, browser-based Flappy Bird clone built with HTML5, CSS, and JavaScript featuring smooth physics and retro arcade gameplay.

[![Play Game](https://img.shields.io/badge/▶_Play-Game-success?style=for-the-badge&logo=gamepad)](https://heysanzu.github.io/sanzuFlappy)

![Thumbnail](src/flappyUI.png)

Fly through endless obstacles in this web-based Flappy Bird game! Built purely with HTML, CSS, and modern JavaScript, featuring responsive controls, high-score tracking, and clean 2D graphics.
